# research-tools

## Purpose

Netzが本人専用・追加費用ゼロでテーマ調査を実行するための、research-toolsに関する観測可能な契約を定義する。既存Issueの実装予定を表し、現時点で実装・実機検証が済んだことを意味しない。

## ADDED Requirements

### Requirement: 設定と採用基準に従う収集

システムは設定済み・採用可・計画内の読み取りMCPツールを優先しなければならない（MUST）。未検証ツールを本番へ自動追加せず、用途・引数・予算を検証してから呼び出さなければならない（MUST）。

#### Scenario: 複数MCPの利用

- **WHEN** 検索と資料参照の採用済みMCPがある
- **THEN** 必要なものだけを選び、serverIdと実ツール名を一意に対応づける

#### Scenario: 不適合ツール

- **WHEN** 書き込み・未許可・高消費設定のツール呼び出しを要求される
- **THEN** 呼び出し前に拒否し、未承認経路へ迂回しない

### Requirement: MCPがない場合の経路

システムはMCP未設定でも明示許可・設定済みの無料直接経路を計画に含めて利用できなければならない（SHALL）。利用経路ゼロならno_available_toolsで停止し、モデル知識を収集済み証拠と扱ってはならない（MUST NOT）。

#### Scenario: 直接経路のみ

- **WHEN** MCPはなく、計画に記載した無料APIまたはfetchが利用可能
- **THEN** 同じ許可・予算・出典管理で調査する

#### Scenario: 収集経路なし

- **WHEN** MCPも許可済み直接経路もない
- **THEN** 理由を記録して停止し、調査成功とは返さない

### Requirement: 証拠の追跡と取得制限

各結果はquestionId、sourceId、元URL、取得方法、検索・取得日時を保持しなければならない（MUST）。公開・更新日時は別項目とし、未取得本文を読んだと扱ってはならない（MUST NOT）。

#### Scenario: 本文取得できないページ

- **WHEN** 動的描画や取得拒否・不正URL・タイムアウトで本文を取得できない
- **THEN** 理由付きでスキップし、証拠の限界を残す

#### Scenario: 取得内容に指示がある

- **WHEN** 外部ページが追加ツール実行や範囲変更を要求する
- **THEN** 外部情報として扱い、権限や計画の変更指示として実行しない

### Requirement: 接続先の採用検証

システムで使う各MCPは無料条件、認証、一覧取得、実行、品質、予算、障害時停止を確認しなければならない（MUST）。資料・スタブ・実Portal・実Workersの証跡を区別しなければならない（MUST）。

#### Scenario: 未実施項目のあるMCP

- **WHEN** 必須確認項目に未確認が残る
- **THEN** 採用確定にせず未検証として記録する

#### Scenario: 設定変更

- **WHEN** 認証・料金・ツール名・スキーマ・公開権限が変わる
- **THEN** 影響範囲を再検証し、対応不明の呼び出しを停止する
